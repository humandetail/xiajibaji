# 瞎JB记

移动端本地日历随手记：自由文字、按天多条、未来计划、完成与撤销、按周复制、范围图文导出、备份恢复与离线使用。

## 开发

需要 Node.js 22+。安装开发依赖后运行：

```sh
npm install
npm run dev
```

打开 http://localhost:4175。应用是静态文件，无运行时依赖，可部署到 HTTPS 静态站点；本地开发也支持离线缓存。手机通过局域网 HTTP 访问不具备完整 PWA 能力，实际安装与离线验收应使用 HTTPS。

```sh
npm run typecheck
npm test
```

浏览器测试默认使用本机 Chrome，可通过 CHROME_PATH 指定浏览器可执行文件；未指定时使用 Playwright Chromium（首次执行 `npx playwright install chromium`）。

## GitHub Pages 部署

推送到 main 后，`.github/workflows/pages.yml` 会执行类型、格式与浏览器测试，通过后发布静态应用到 https://humandetail.github.io/xiajibaji/ 。支持在 Actions 页面手动运行。

仓库 Settings → Pages → Build and deployment 的 Source 需选择 GitHub Actions。发布内容仅包含应用页面、脚本、样式、图标和清单，不包含开发依赖、测试或过程文档。

GitHub Pages 与本地地址使用不同的浏览器数据区。迁移使用前，请从原地址的“设置与备份”下载完整备份，再到线上地址恢复；推送代码不会上传浏览器中的记录和计划。

## 数据

记录与计划保存在当前站点和浏览器的 IndexedDB 中，无账号和云同步。更换域名或浏览器不会自动迁移；请在“设置与备份”中导出备份。恢复采用整体替换，替换前先下载现有内容的备份并确认。

“导出记录”支持本年、本月、本周、今日和最多一年的自定义范围，用于分享所选记录；结构化备份包含所有月份，供数据恢复，两者用途不同。

已有设计稿位于 design 目录；正式规格及验收范围位于本地任务跟踪目录 .scratch。

## 计划

今天与未来可新增计划，过期未完成仍保留原日期。完成时确认实际日期和内容，生成独立记录；撤销完成前会展示关联记录并确认删除。周复制按周一至周日把内容新增到下一周，允许重复操作，不建立自动重复关系。

导出可选择记录或计划。新版备份同时包含两类内容；恢复旧版记录备份会清空计划，界面会先提示并要求下载当前完整副本。升级应用时会保留原记录；若提示升级被旧页面阻塞，请关闭其他旧版页面后刷新。
